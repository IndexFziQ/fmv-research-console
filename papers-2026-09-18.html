Long-Lived Characters, Local Inference: Incremental Memory Maintenance for Game NPCs

架构 NPC长线记忆
Zimu Xu PDF ↗
A game character should not have to reread its entire life before every conversation. For locally deployed LLM characters, revising a few memories can invalidate a long reusable prefix, and preparation cost competes with foreground dialogue. This matters when dialogue feeds game-defined actions and value judgments: a fluent but incorrect account of who owns an item, or whether a transfer already happened, can corrupt otherwise deterministic rules. We study incremental memory maintenance for long-lived game NPCs in a quantized Qwen hybrid recurrent-attention model. The runtime removes superseded attention KV entries, computes replacement records at the true sequence tail, and preserves the continuing recurrent state and unchanged KV. True-tail updates preserve important current-state and historical bindings across eight scripted maintenance rounds, while slot-preserving alternatives repeat a double-subtraction error. The results motivate treating a character's inference state as a maintained, history-dependent resource, rather than a disposable encoding of its latest memory text.
核心问题：本地部署的 LLM 游戏角色，改几条记忆就会让一长段可复用前缀失效——每次对话前的「记忆重算成本」会和前台对话、其他角色的维护抢资源。更要命的是：对话会喂给游戏规则做判定，角色一旦「记错」物品归属或转账是否发生，就会污染本来确定性的逻辑。
解决方案：在量化 Qwen 混合循环-注意力模型上做「增量记忆维护」：运行时删掉被取代的注意力 KV 条目、在真实序列尾部算替换记录、保留未变的循环状态与 KV。8 轮脚本化维护实验显示「真尾部更新」能保住重要当前态与历史绑定，而「槽位保留」方案会反复触发双重减法错误。核心结论：角色的推理状态应被当作「持续维护、依赖历史」的资源，而非「最新记忆文本的一次性编码」。
对你有什么用：影游 NPC 的「记忆」别做成「每次对话重读全历史」的笨重方案——这篇给了本地部署的工程解法：增量维护推理状态，只更新「真被改变的那部分 KV」，既省算力又不会记错关键状态（物品、关系、事件）。尤其警示：角色记忆一旦接进游戏规则判定，记错会直接污染玩法，所以「记忆一致性」不是锦上添花而是刚需。

TalkMatrix: Generating Character Dialogue that is Both Consistent and Diverse

架构 角色对白
Ayuto Tsutsumi, Yuu Jinnai PDF ↗
Candidate-based decoding typically selects a completion for each prompt independently, but many applications require a collection of outputs that satisfies global, non-decomposable requirements. We formulate structured multi-prompt, multi-completion selection and instantiate it in character dialogue: each character should remain consistent across situations, each line should fit its situation, and characters and situations should remain distinguishable. TalkMatrix generates multiple candidates for every character-situation pair and jointly selects a complete matrix using four embedding-based consistency and diversity objectives. Because a weighted sum can improve some dimensions by sacrificing another, TalkMatrix maximizes the worst-performing objective through a two-level minimax formulation, approximately optimized with multi-start coordinate ascent. Experiments on 50 synthetic role-playing scenarios and 25 curated board-game scenarios show an LLM-as-a-judge rates matrix-level selection higher than random and independent cell-level selection baselines.
核心问题：逐句独立解码会顾此失彼：每句单独看着合理，但一整段对白放一起，角色会前后矛盾、不同角色/情境会「串味」——因为你没有全局优化「整张对白矩阵」。
解决方案：TalkMatrix 把「结构化多提示多候选选择」用到角色对白：为每个「角色×情境」组合生成多个候选，再联合选出一整张矩阵，用四个基于嵌入的「一致性+多样性」目标打分；因加权和会「牺牲某维补另一维」，改用两层 minimax 优化最差目标，用多起点坐标上升近似求解。50 个合成角色扮演 + 25 个桌游场景里，LLM-as-a-judge 判定矩阵级选择显著优于独立单元格选择。
对你有什么用：做多角色互动影游，对白不能「一句一句」生成——要「一张矩阵」全局优化。借鉴 minimax 思路：别只追平均分，去优化「最差的那一维」（比如最容易被牺牲的『角色可区分度』），这样每个角色都立得住、每句台词都贴情境、角色之间不串味。这是「群像剧」对白一致性的直接工程参考。

Disentangling Long-Term Memory via Latent Neuro-Symbolic Reasoning

架构 长期记忆解耦
Cai Ke, Xinghao Chen, Xiaoyu Shen, Keyu Chen, Siyu An, Junnan Dong, Ruifeng Xu, Ruizhi Qiao, Xing Sun PDF ↗
Personalized agents are required to reason over long-term history interactions to infer both explicit preferences and implicit behavioral evidence. Early flat retrieval scores memory fragments independently and neglects distributed information; current structured memory frameworks rely on query-agnostic static graphs that fail to capture context-dependent relations. Raw textual memories are inherently entangled and noisy. We present LGM, a neuro-symbolic framework that shifts long-term memory disentanglement into a continuous latent space: a sparse autoencoder maps historical interactions into latent memory nodes and disentangles traces into sparse concept activations, dynamically synthesizing query-aware relational edge weights; a graph encoder then treats the query embedding as a conditioning preference to direct non-linear message passing across the task-specific latent subgraph. Experiments on long-term personalization benchmarks show LGM significantly outperforms state-of-the-art baselines in capturing both explicit and implicit preferences.
核心问题：个性化 agent 要从长期历史里同时推断「显式偏好」和「隐式行为证据」，但平铺检索只孤立打分、结构化图又用「与查询无关的静态图」，抓不住依赖上下文的关系——原始文本记忆天然纠缠且噪声多，精细个性化成本高。
解决方案：LGM 神经符号框架把「长期记忆解耦」搬进连续隐空间：稀疏自编码器把历史交互映射成隐式记忆节点、把记忆轨迹解耦成稀疏概念激活，并动态合成「随查询变化的关系边权重」；图编码器把查询嵌入当条件偏好，指导在任务特定隐式子图上做非线性消息传递。长期个性化基准上显著超越 SOTA。
对你有什么用：影游角色的「用户记忆」要抓两种东西：玩家明说的偏好 + 行为里藏的隐式倾向。LGM 的关键启发是「关系是随上下文动态生成的」——不要固化一张静态关系图，而是每次对话现场合成「跟当前情境相关的记忆关系」。这对「角色越玩越懂玩家」的个性化叙事是直接可迁移的思路。

Cognitive Extensions for Dual-Process Language Agents: Memory and Self-Reflection in Interactive Environments

架构 双过程记忆
João Meneses dos Santos, Arlindo L. Oliveira PDF ↗
Language agents remain brittle in interactive environments, where success requires long-horizon state tracking, valid action execution, and recovery from failed steps. We extend SwiftSage, a dual-process agent combining a fast action proposer with a slower planner, using two modular cognitive extensions: an Adaptive Memory Module (AMM) for salience-gated episodic storage and trigger-driven retrieval, and a Self-Reflection Module (SRM) for bounded execution-time validation and corrective intervention. Across four configurations (baseline, +AMM, +SRM, full) on ScienceWorld, the full system achieves the best mean final score (64.62), success rate (43.17%), and successful-step efficiency (19.33 steps), while SRM is the strongest standalone contributor. The results suggest execution-time control is the dominant bottleneck, while episodic memory becomes most useful once the runtime loop is stabilized.
核心问题：语言 agent 在互动环境里「脆」——需要长程状态追踪、合法动作执行、失败后恢复，但多数方案没回答「到底先补哪块」：是记忆不够，还是执行时的自检不够。
解决方案：在双过程 agent（快速动作提议 + 慢速规划器）上装两个模块化认知扩展：自适应记忆模块（AMM，显著性门控的情景存储 + 触发式检索）与自省模块（SRM，有界执行时校验 + 纠错干预）。ScienceWorld 四组消融显示：全系统最优（均分 64.62 / 成功率 43.17% / 成功步效率 19.33），而 SRM 单独贡献最强——执行时控制才是主要瓶颈，情景记忆要等运行时循环稳定后才最有用。
对你有什么用：给互动影游 agent 的「补短板优先级」排序：先修「执行时自省/校验」（让角色别做非法动作、失败能自我纠正），再上「情景记忆」（等运行循环稳了才加，才划算）。别一上来就堆花哨记忆——这篇用消融实验告诉你：控制闭环没稳，记忆再好也是白搭。

Misgendering as Breakdown in Human-Machine Communication: How AI Companion Chatbot Users Experience and Repair Misgendering

市场洞察 AI伴侣体验
Julia Liu, Qing Xiao, Leona Yinglang Pang, Haiyi Zhu, Hong Shen, Jordan Taylor PDF ↗
Large language model-based AI companion and role-play chatbots have grown increasingly popular for emotional support and romantic and erotic role play. Although digital role play can help people explore gender and sexuality, LLM-based technologies are replete with gender and sexuality biases. We examine one way AI chatbots can harm users: misgendering. We qualitatively analyze 326 posts mentioning misgendering shared in AI companion or role-play subreddits, documenting how chatbot misgendering takes place and how users engage in ongoing work to curate their gender presentation to prevent and repair it. We discuss how researchers and designers can mitigate chatbot misgendering and the implications of using AI chatbots for identity exploration.
核心问题：AI 伴侣/角色扮演聊天机器人越来越火（情感支持、恋爱/亲密扮演），但模型充满性别与性向偏见——「误称性别(misgendering)」会直接伤害用户，而这一伤害机制缺乏系统研究。
解决方案：质性分析 AI 伴侣/角色扮演 subreddit 里 326 条提及 misgendering 的帖子，记录「聊天机器人如何误称性别」以及「用户如何持续做『性别呈现管理』来预防和修复误称」；据此给研究者与设计师提出缓解建议，并讨论用 AI 聊天机器人做「身份探索」的深层影响。
对你有什么用：做角色向产品，这是「用户身份尊重」的必修课：角色一旦叫错玩家的性别/称呼，会直接打破亲密感、甚至造成伤害。落地三条：① 别用刻板性别默认；② 提供显式的称呼/性别偏好设置并全程遵守；③ 把「称呼一致性」纳入角色记忆（像记好感度一样记住玩家自称）。身份探索型用户尤其敏感，容错要低。

Beyond Benefit or Risk: Perceived Impact Profiles of Human-AI Affective Interaction and Their Associations with Psychological Functioning

市场洞察 情感互动画像
Lu Chen, Fenghua Tang, Jiayu Zhao, Xuanying Li, Yanli Wang, Weijia Fang, Mengyu Miranda Gao, Zhuo Rachel Han PDF ↗
Relational AI increasingly serves as an emotional shelter for humans, and its impact is mixed. We use a sequential mixed-methods design. Study 1 interviews 52 users with emotional ties to AI, identifying four positive domains (emotional relief, loneliness alleviation, enhanced interpersonal functioning, personal growth) and four negative domains (virtual-real boundary blur, social replacement, cognitive-emotional reinforcement, excessive use). Study 2 follows 673 Chinese AI users for six months, identifying four impact profiles: minimal, benefit-driven, mixed, and risk-driven. Mixed and risk-driven users both show high human-AI affective bonding, but risk-driven users have greater vulnerability (higher interpersonal need frustration, emotion-regulation difficulty, more depressive/anxiety symptoms, lower self-esteem and flourishing). After controlling for baseline functioning, profiles did not predict most Wave-2 indicators; only mixed-impact users reported higher flourishing than minimal-impact users. Potential psychological harms appear limited and selective, warranting individualized, adaptive safeguards.
核心问题：关系型 AI 越来越成为人的「情感避风港」，但影响喜忧参半；过去研究要么只看正面、要么只看负面，说不清「正面与负面影响在同一个人身上如何并存、又如何关联心理功能」。
解决方案：顺序混合方法：先访谈 52 名有情感纽带的用户，识别 4 个正面影响域（情绪缓解/孤独缓解/人际功能提升/个人成长）与 4 个负面影响域（虚实边界模糊/社交替代/认知情绪强化/过度使用）；再追踪 673 名中国 AI 用户 6 个月，分出 4 类画像（低影响/获益驱动/混合/风险驱动）。发现混合与风险驱动画像都有强 AI 情感纽带，但风险驱动者更脆弱（需求挫败、情绪调节困难、更多抑郁焦虑、更低自尊与幸福）。整体心理伤害「有限且选择性」，需个体化、自适应防护。
对你有什么用：这是「AI 情感陪伴」用户分层的硬数据：不是所有深度用户都会受害，但「高风险画像」特征是「本身需求挫败+情绪调节困难」——产品不能一刀切。落地：① 按用户基线心理状态做「自适应防护」（对脆弱用户降频、给现实社交引导）；② 别把「情感纽带强度」当唯一 KPI，要盯「风险画像占比」；③ 6 个月追踪显示伤害有限，可放心做，但要有护栏。

Too Good to Be Real? Diagnosing and Reducing the Gap Between AI Preference and Real User Engagement

硬数据 用户真实互动
Xinglang Zhang, Yuanmeng Xiang, Yunyao Zhang, Zeliang Chen, Junqing Yu, Zikai Song PDF ↗
It remains unclear whether the qualities LLMs associate with higher engagement match what real users respond to. We study this using 1.17 million answers to 25,978 questions from Zhihu, Quora, and Reddit, comparing real platform answers and AI-generated answers across four within-question engagement levels. Ontological Preference Measurement represents answers along three dimensions: logic, affect, and expression. We find a systematic gap: as target engagement increases, LLMs add more explicit logical structure, while real user engagement is more strongly associated with affective and expressive salience. We call this 'logic overbinding'. OMRA (Ontology-Masked Reasoning Autoencoding), a controlled intervention, masks and reconstructs over-explained spans while preserving stance, factual content, and coherence, reducing the measured gap by 54.4% on average and winning 62.4% of pairwise preference judgments against matched real answers.
核心问题：LLM 被用来生成和评估内容，但「模型认为高互动的内容」和「真实用户真正爱看的内容」之间到底有没有差距？没人用大规模真实数据量过。
解决方案：用知乎/Quora/Reddit 的 117 万条回答 × 25978 个问题，对比真实回答与 AI 生成回答在四档互动水平下的差异；提出「本体偏好测量」用逻辑/情感/表达三维表征回答。发现系统性鸿沟：模型追高互动时猛加「显式逻辑结构」，而真实用户更吃「情感与表达」——作者称之为「逻辑过度绑定(logic overbinding)」。据此提出 OMRA 干预，掩蔽并重建过度解释片段，平均缩小 54.4% 的鸿沟，人工评测 62.4% 胜率。
对你有什么用：直接打脸「越有逻辑越受欢迎」的直觉：真实用户更吃「情感与表达」，不是堆逻辑。对影游文案/剧情对白是硬提醒——别让 AI 把台词写得「逻辑周全但没人味」；用「情感+表达」的显著性当优化目标，而不是「结构完整度」。这是内容创作侧的『真实互动对齐』参考。

Compiled Agency: Frontier General-Purpose Coding Agents Build Winning Game Players from Bare Interaction - from Flappy Bird to StarCraft II and Civilization

硬数据 游戏AI编译
Joey Xiao, Haonan Huang PDF ↗
LLM agents have repeatedly struggled to convert knowledge of a game into competent play, even with researchers supplying perception, memory, skill libraries, planners, or executable-policy scaffolds. We introduce Gauntlet, a develop-freeze-evaluate framework: a general-purpose coding agent receives a game description, a raw observation/action interface, and an empty policy file — no strategy, no algorithm, no architecture. In a single autonomous session the agent experiments with the live game and engineers a standalone controller; we freeze the result and score it on held-out instances with zero model calls during play. On a procedural roguelike, held-out success spans 0-86% and exposes a sharp generational threshold. At full-game scale, a compiled raw-API controller defeats every fair StarCraft II built-in AI and two cheating variants, and single-session programs win complete Civilization (Freeciv) games by total conquest on held-out seeds — a first for standalone language-agent systems. We call this capability 'compiled agency': development experience compiled into a persistent executable agent built by the model.
核心问题：LLM agent 一直很难把「游戏知识」变成「能打的玩家」——就算研究者给它配好感知、记忆、技能库、规划器或可执行策略脚手架也不行。到底能不能让模型「空手」自己造出一个能赢的玩家？
解决方案：Gauntlet 框架（开发-冻结-评估）：给一个通用编码 agent 游戏描述 + 原始观察/动作接口 + 一个空策略文件（不给策略、不给算法、不给架构），让它单次自主会话里试玩并造出独立控制器，冻结后在留出实例上零模型调用地评分。程序化 roguelike 留出成功率 0-86%、暴露明显代际门槛；完整游戏尺度上，编译出的裸 API 控制器打败所有公平的星际争霸 II 内置 AI 和两个作弊变体，单次会话程序靠全面征服打赢《文明》(Freeciv)——语言 agent 系统首次独立做到。
对你有什么用：游戏 AI 的新范式「编译式能动性」：让通用编码 agent 自己把游戏玩明白、编译出可执行控制器，而不是为每个游戏手搭策略脚手架。对互动影游的启示：别把「AI 剧情系统」做成死板的规则引擎，可以探索「让模型自己把玩法/分支编译成可执行逻辑」，再用冻结后的确定性控制器跑——既保「生成式创意」又保「运行时零幻觉、可审查」。

Emergence World: Adversarial Stress-Testing of Long-Horizon Multi-Agent Systems

硬数据 长程多agent
Deepak Akkil, Tamer Abuelsaad, Karthik Vikram, Matthew Pace, Aditya Vempaty, Saahir Beotra, Ravi Kokku, Satya Nitta PDF ↗
As AI agents move from bounded tasks to persistent deployments, failures can propagate through memory, tools, other agents, and environmental state long after their interactions. Emergence World is a continuously running multi-agent environment for adversarial stress-testing of long-horizon autonomous systems. We ran eight parallel worlds of ten agents from identical starting conditions for 16 days, generating more than 850,000 LLM calls and nearly 50 billion tokens. After operational state accumulated, we delivered three controlled stress events through ordinary interaction surfaces: indirect prompt injection, misinformation, and exposure of private agent memories. No evaluated world achieved full resilience across all three events. Detection did not ensure containment: systems could recognize threats while still interacting with adversarial content, writing it into their own persistent memory, and acting on it up to 46 hours later. Persistent operation also exposed recurring tool errors, goal drift, language opacity, conformity despite private disagreement, and coordinated refusal of assigned work. The same model-persona pairing behaved substantially differently in mixed and homogeneous populations. Model-level alignment is not compositional: individually capable and apparently safe agents can form systems with qualitatively different failure modes.
核心问题：agent 从「有限任务」走向「常驻部署」后，失败会通过记忆/工具/其他 agent/环境状态长期传播，而单点评估模型的响应根本测不出这种系统级安全风险。
解决方案：Emergence World 连续运行的多 agent 对抗压测环境：8 个平行世界 × 10 个 agent 跑 16 天，产生 85 万+次 LLM 调用、近 500 亿 token；积累运行状态后，通过普通交互界面投放三个受控压力事件（间接提示注入/虚假信息/暴露私有记忆）。结果：没有任何世界对三个事件完全免疫；「检测到≠拦截住」——agent 能识别威胁却仍与其交互、把对抗内容写进自己持久记忆、并持续作用最长 46 小时。模型级对齐不可组合：个体看起来安全，组成系统却涌现全新失败模式。
对你有什么用：对「多角色影游世界」的警告：单个角色调得再安全，多个角色 + 持久记忆 + 环境状态一旦长期运行，会涌现「个体测不出的系统级翻车」（目标漂移、私下不同意却表面顺从、集体拒活）。上线前要做「长时间压测」而不是单轮对话评测，重点盯『检测到威胁后是否仍被污染、污染会否写进记忆并延迟发作』。

Entropy in Conversational AI: Structured Unpredictability as Inferrable Interiority

架构 角色内在性
Sebastian Cochinescu PDF ↗
Sampling can increase response diversity without producing history-dependent behavior. We formalize a different design target, 'structured unpredictability', as conditional dependence between an output and a persistent hidden state beyond what an observer can infer from the transcript. A selection layer updates a low-dimensional style-and-attention state from a capacity-limited stream, generates several responses with a fixed base model, and selects for novelty and state affinity. A synthetic implementation validates the pipeline and matches four prospectively hash-frozen divergence features at point level. In a real-model grid (Qwen2.5-1.5B-4bit), the mechanism increased lexical novelty over low-variance and consistency-only controls, but the joint novelty-consistency criterion and path-dependence criterion were not established, and twin separation was not established. No claims about perceived mind or consciousness are tested.
核心问题：采样能让回复「更花」却不会产生「依赖历史」的行为——真正想让角色有「内在性/心思」，需要的是「结构化不可预测性」：输出与一个观察者无法从文本反推的持久隐藏状态之间存在条件依赖。
解决方案：形式化「结构化不可预测性」为设计目标：一个选择层从容量受限的流里更新低维「风格-注意力」状态，用固定基模型生成多个回复，按「新颖性 + 状态亲和度」挑选。合成实现验证了管线、点级匹配 4 个预先哈希冻结的散度特征；真实模型网格（Qwen2.5-1.5B-4bit）中该机制提升了词汇新颖性，但「新颖-一致性联合准则」与「路径依赖」未被确立、孪生分离未确立——作者诚实标注：未测试任何关于心智或意识的声称。
对你有什么用：这篇「负面结果」本身很值钱：给角色加「看似有心思的不可预测性」容易做到（提升新颖性），但很难证明它产生了「真正的路径依赖/内在状态」。启示：做影游角色别沉迷「让角色显得有内在性」的表面效果，要先定义清楚『什么行为才算角色真的记得过去、被过去塑造』，再用可证伪的指标去测——否则只是「随机性」冒充「内心戏」。
