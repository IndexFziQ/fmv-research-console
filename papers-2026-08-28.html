VoiceMem: Streaming Dual-Brain Memory for Real-Time Interaction

落地 语音记忆
Zhifei Xie, Jiaqi Lang, Ze An, Yifan Zhao, Dongchao Yang, Kai Li, Ziyang Ma, Mingbao Lin, Chunyan Miao, Shuicheng Yan PDF ↗
Conversational systems, such as duplex speech language models (SLMs), still lack a streaming, accurate, and empathetic memory system as their soul. We introduce VoiceMem, a simple memory architecture with a parallel informational left brain, an emotional right brain, and streaming memory I/O mechanisms. We further build a complete pipeline for memory-aware SLM training, long-horizon evaluation, and decoupled deployment with interchangeable memory backends.
核心问题：语音对话模型（duplex SLM）能实时说，却「记不住也共不了情」——缺一套流式、准确、有同理心的记忆系统当灵魂。
解决方案：VoiceMem 用「双脑」架构：左脑管信息（事实记忆），右脑管情绪（短期+长期情感归因 + 双节点人格建模），外加流式记忆读写。左脑 top-5 检索比 Mem0 的 top-200 还高近 30 分；右脑在三个人格基准上刷新 SOTA、总分 +4.29；检索 134ms 完成，不增加对话延迟，且已在真实环境部署。
对你有什么用：做影游语音角色，记忆系统要「信息 + 情绪」双轨并行。角色不光要记得你说过什么，还要记得「当时是什么情绪」，这样才能在合适时机带感情地接话，而不是机械复述事实。

Super Star: Towards Streaming Real-time Interactive Agents for Digital Humans

落地 数字人
Wentao Jiang, Youchen Xie, Haidi Fan, Yajing Chen, Xin Wang, Ye Shi, Jingya Wang PDF ↗
Existing co-speech gesture generation methods are predominantly studied in offline settings. Interactive digital humans in real-world scenarios are required to generate speech-synchronous gestures online. We propose a real-time interactive framework that couples a streaming speech response module with an online gesture generation module, using a causal multimodal autoregressive model that predicts body motion from streaming response speech and motion history.
核心问题：数字人的「说话时配手势」大多只能离线做——要等整段语音生成完才能配动作，根本没法用在实时互动里。
解决方案：Super Star 把「流式语音回复」和「在线手势生成」耦合成一个因果多模态自回归模型，边出语音边凭历史动作预测下一个身体动作，不偷看未来语音。还建了虚拟陪伴场景的离线数据合成管线 + 在线用户反馈自进化闭环。
对你有什么用：做互动影游的虚拟角色/数字人，语音和肢体动作要「边生成边同步」。这套流式框架能避免角色「说完话手还没跟上」的呆滞感，让虚拟角色实时、自然地带手势说话。

Learning What to Share and What to Personalize: Hierarchical Strategy Co-Evolution for Agent Memory

Memory-augmented agents maintain compact user profiles, but existing methods use a static, one-size-fits-all strategy. We propose HiPS, a framework that decouples memory management into a globally shared foundation and a user-specific adaptive tier, with Universal Strategy, Persona Delta Distillation, and Cross-Level Rule Flow.
核心问题：记忆型智能体给每个用户维护「用户画像」，但「该记什么、该压缩什么、该丢弃什么」的策略是训练前就定死的——一个套路套所有人，个性化做不出来。

对你有什么用：影游角色对每个玩家要有「专属记忆策略」——同一个角色，对喜欢剧情的玩家多记世界观、对喜欢聊天的玩家多记私人话题。别用一套静态记忆策略套所有人。

Reconstructing the Right Episode: Evaluating Interleaved Conversational Memory Beyond Long Context

We introduce SCALE-QA, a constraint-grounded task QA benchmark for flat unsegmented threads targeting episode integrity failure, and TSIM, which segments the turn stream into coherent episodes and indexes them through a hierarchical multi-view memory stack.
核心问题：聊天助手一条长线程里混着多个话题，系统得判断「早先哪段对话」才让「现在这个任务」成立。现有长上下文/记忆基准都暴露了话题边界，低估了这种「扁平混话题」的难度。

对你有什么用：影游长对话里，角色要能「回想正确的那段旧剧情」来支撑当下决策——不是简单记住，而是把对话切成剧情片段、按相关性路由检索。TSIM 的分段思路可直接借鉴到角色记忆系统。

4DStreamCtrl: Interactive Video Generation with Online 4D Control

工具 交互视频
Shiqian Li, Chenguo Lin, Zhiguang Liu, Yu Tang, Jiarong Ou, Rui Chen, Yixin Zhu PDF ↗
We show that camera motion, object trajectories, and depth can be unified into a single 3D point-track representation, from which one model performs joint camera and object control, depth editing, and motion transfer in a single forward pass. 4DStreamCtrl runs at 20 FPS for 480p video and stays temporally coherent over hundreds of frames.
核心问题：生成式视频模型想当「互动工具」，核心卡在精细控制——相机路径法只能转镜头不能动物体，2D 轨迹法不管深度遮挡，3D 法只能离线跑固定长度。没有一种能把「相机+物体+深度」统一且实时。
解决方案：把相机运动、物体轨迹、深度统一成单一 3D 点轨迹表征，一个模型单次前向同时完成相机/物体控制、深度编辑、运动迁移。蒸馏成因果流式模型，480p 跑 20 FPS，数百帧保持时序连贯。
对你有什么用：做互动影游的「实时分支画面」——玩家一个选择，画面里镜头和物体能实时跟着变（而不是只能播预渲染片段）。这是互动影视走向「真实时交互画面」的关键底座。

Code World Model: Coding Agent as World Brain

架构 世界模型
Yiwen Chen, Guosheng Lin, Chi Zhang PDF ↗
World models aim to simulate how complex environments evolve. We introduce Code World Model, which separates world evolution from visual realization: a coding agent serves as the world brain, generating executable code to maintain persistent world state, and a video model renders high-fidelity visual observations conditioned on a proxy video.
核心问题：现有视频世界模型只从「画面」学世界怎么变——学到的是结果，不是背后的规则和机制，所以后果难持久、演化难开放。
解决方案：Code World Model 把「世界演化」和「视觉呈现」解耦：编码智能体当「世界大脑」，用可执行代码维护持久世界状态、做规则一致的演化；再用 proxy 表征桥接，让视频模型渲染高保真画面。在游戏画面数据上微调后，MiniMax-H3 能按代码指定的时空规格渲染出细节丰富的画面。
对你有什么用：影游的世界一致性可以「代码管逻辑、视频模型管画面」。用代码维护角色状态/物品/事件后果（可持久、可推理），画面交给生成模型——比纯端到端视频生成更可控、不穿帮。

AffectSim instantiates emotion-expressive human motions as replayable 3D episodes in which distance, orientation, occlusion, scene geometry, and agent viewpoint can be systematically varied while preserving the underlying behavior and emotion label. It contains 27,647 episodes across five emotion categories and 57 scenes.
核心问题：情感感知基准全是「固定录像」——观测条件在推理前就锁死，没法研究「具身视角（距离/角度/遮挡）如何影响情绪识别」。

Freeman Jiang, Ramon Sanabria, Soham Deshmukh, Bandhav Veluri, Simon Michael Vuch Williams, Elliott K. Suen, Garreth Lee, Kevin Yoonho Choi, Takuya Um PDF ↗
TurnBench pairs a 30-hour, hand-labeled corpus of dyadic human conversation with a standardized evaluation protocol for end-of-turn and interruption detection. Speakers in natural conversation take turns speaking and listening, deciding in real time when to take, hold, or yield the floor.
核心问题：真人对话会实时判断「该接话/该停/该让」，但话轮转换评测一直缺一套统一的、有语言学依据的协议和多样本标注数据。
解决方案：TurnBench：30 小时人工标注的双人对话语料 + 标准化评测协议（话尾检测 + 打断检测），覆盖 6 种互动风格、三重标注。评测 14 套系统发现：话尾召回跨风格稳定，但打断误报高度依赖风格、集中在 backchannel 密集场景；流畅转接时真人会提前 151ms 开口，现有系统无一能无代价做到。

ClueWeaver: Reward-Guided Dual-Agent Evidence Reasoning for Compact LLMs on Literary Long Narratives

工具 叙事推理
Jihao Zhu, Zhiwei Yang, Wenxiao Zhang, Junqian Zhao, Qi You, Fangqi Wang, Zheyuan Deng, Hanzhe Yang, Yu Liu, Jin B. Hong PDF ↗
ClueWeaver is an evidence-aware dual-agent framework for long-narrative question answering with compact local models. A Finder identifies passages containing answer-critical clues, while an Interpreter derives the answer from the selected evidence, producing rationales with paragraph-ID citations.
核心问题：读小说、剧本、档案这类长叙事材料做问答，要用昂贵的闭源长上下文模型；本地小模型直接喂全文成本高、难审查、还容易漏掉稀疏证据。

Beyond Local Surprise: Grounded Dialogue as Selective Belief Revision under Referential Uncertainty

技术参考 对话理解
Ziming Liu, Bhanu Chaitanya Jasti, Ziyang Xu, Hongyu Wu, Yi Wu, Jiqun Liu PDF ↗
When a speaker refers to a scene the listener cannot directly see, the listener must decide whether to preserve its current understanding or revise it. We find local mismatch promotes preservation, whereas accumulated uncertainty promotes revision, consistent with conceptual pact theory.
核心问题：对话里对方提到你看不见的场景时，你该「保留」还是「修正」自己的理解？现有系统一看局部不一致就立刻改，但这可能越改越乱。
解决方案：控制变量对比四种理论驱动的「保留/修正」策略，发现反直觉结论：局部不匹配反而促进「保留」，累积的不确定性才触发「修正」——听者会在局部矛盾面前坚持先前理解，只有不确定积累到阈值才改。这与概念契约理论一致。
对你有什么用：影游角色和玩家对话时，别让角色一听到「对不上」就立刻改口推翻自己。真正的对话者会先守住共同理解、等证据攒够了才修正——这对角色对话的一致性和可信度很关键。
