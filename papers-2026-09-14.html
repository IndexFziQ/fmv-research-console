But How Would AI Agents Run a Town's Economy?

硬数据 世界模拟
Sajal Regmi, Siddhartha Pudasaini, Chetan Phakami Pun PDF ↗
We placed 100 memory-equipped large language model (LLM) agents in charge of a closed, money-conserving spatial economy on real Pokhara Lakeside geography (earning wages, running businesses, setting prices) and ran this multi-agent simulation for up to 26 simulated weeks, well past the 1-2 weeks typical of agent-society studies. Across 91 validated runs (2.44M agent decisions, 21.5B tokens), the money stops moving, in a specific and measurable way. A 12x tourist demand shock raises business revenue 4.62x (p<0.001), decomposed exactly into a 1.50x extensive margin and a 3.07x intensive margin. Monetary transmission stops there: wages move 1.03x (p=0.42); 0.3% of 3,981 menu items are ever repriced. A randomized cash transfer shows 96.7% still held 311 pulses later, marginal propensity to consume 3-4%, indistinguishable from zero. The wealth distribution is near-frozen at short horizons (rho=0.964 over 2 weeks) but not frozen: rho falls to 0.752 at 26 weeks. Swapping the backing LLM moves every outcome (p=0.0039); deleting agents' memory moves none detectably.
核心问题：让 LLM agent 真正「过日子」会怎样？现有 agent 社会模拟只跑 1-2 周，看不清经济与社会的长期演化——agent 会不会消费、会不会定价、财富会不会流动，都没有可靠答案。
解决方案：把 100 个带记忆的 LLM agent 放进真实博卡拉湖滨地理的封闭货币经济（挣工资、开店、定价），连跑 26 周（2.44M 决策、21.5B token）。发现钱「停止流动」：12 倍游客冲击下商家营收涨 4.62 倍，但工资只动 1.03 倍、0.3% 的菜单被重新定价；随机发钱后 96.7% 仍被持有、边际消费倾向仅 3-4%。财富分布前 2 周看似冻结（ρ=0.964）但 26 周降到 0.752。对照实验显示换底层 LLM 会改变一切结果，而删掉 agent 记忆几乎没有影响。
对你有什么用：影游要做「可长期演化的世界/NPC 社会」，别只跑几轮就下结论——很多社会现象要 12-26 周才浮现（财富冻结→缓慢分化）。且底层模型选择比记忆模块更影响社会行为，选模型前先做长程仿真验证，别把资源都压在记忆架构上。

Using Semantic Uncertainty to Estimate Transition Relevance in Turn-taking

工具 对话节奏
Muhammad Umair, Jan P. de Ruiter PDF ↗
Turn-taking is a fundamental mechanism that governs when interlocutors speak and listen. Although Spoken Dialogue Systems (SDS) exploit a range of linguistic, acoustic, and non-verbal cues, they produce ill-timed responses in unscripted interaction. A central challenge is anticipating Transition Relevance Places (TRPs). Human listeners do not wait for turn endings; as an utterance unfolds, they use expectations about its developing meaning to anticipate TRPs. We examine whether these evolving expectations can be modeled through semantic uncertainty -- an LLM-derived measure of how strongly a turn so far constrains what may plausibly come next. We sample possible continuations of an ongoing turn and use changes in semantic dispersion to identify TRPs within turns. Our approach substantially outperforms prompt-based and fine-tuned text-only baselines on a dataset with TRP labels derived from real-time listener responses.
核心问题：语音对话系统在非脚本互动里「抢话/冷场」——难在预判「话轮转换相关位置(TRP)」：人不会等对方说完才接，而是边说边预测「这里能不能接」。系统如何学会这种实时预判？
解决方案：把「语义不确定性」——LLM 度量「当前话轮对未来可能内容的约束强度」——作为 TRP 信号：采样当前话轮的多种续写，用语义分散度的变化来定位话轮内的可接话点。在带实时听者响应标注的数据集上，该方法大幅超越 prompt 式和微调式的纯文本基线，实证了「演进的语义约束」决定了非脚本互动里的接话时机。
对你有什么用：影游做「实时语音对话/多角色抢白」时，别靠「检测到停顿/话尾」才让角色接话——那样永远慢半拍。学这篇用「语义不确定性」预判：当角色对「对方接下来要说啥」的约束变弱时，就是可以自然打断/接话的时机。

K/V-Cache Interventions Dissociate Representation Alignment from Persona Expression in Decoder-Only Language Models

架构 人设控制
Yu Sun, Mengyin Lu, Cong Feng, Guangming Lu, Huimin Han PDF ↗
We study K/V-cache interventions -- transplanting a target-conditioned K/V trajectory into a source-persona generation -- as a structured surface for persona control in decoder-only language models. Across 13 intervention configurations on Llama-3.1-8B, we report two consistent dissociations between representation-level alignment and behavioral expression. First, all layer-band K/V replacements (early, mid, late) achieve strong local V-space alignment, but only mid-layer replacement (layers 9-20) combines substantial target-marker expression with preserved lexical diversity. Second, full and mid-layer replacement induce comparable alignment yet produce different lexical-diversity profiles (TTR 0.65 vs. 0.77). Third, position perturbations (lag and shuffle) uniformly suppress target-persona expression. Representation-level similarity metrics alone are thus not sufficient predictors of downstream persona expression; the K/V cache emerges as a controllable but structurally constrained intervention surface.
核心问题：想让 LLM 稳定「扮演某个角色」，但「表征对齐」和「行为外显」是两码事——表征层面像了，说出来的话未必像。到底改哪一层、怎么改，才能既保留角色标志、又不牺牲语言多样性？
解决方案：用 K/V cache 干预（把目标角色条件的 K/V 轨迹移植进源角色生成）在 Llama-3.1-8B 上做 13 种配置。发现：① 早/中/晚三层替换都能达到局部 V 空间对齐，但只有中层替换（9-20 层）能同时保留目标角色标志和词法多样性；② 全层与中层对齐度相近，但词法多样性差异大（TTR 0.65 vs 0.77）；③ 位置扰动（滞后/打乱）一致地抑制目标角色表达。结论：表征相似度不足以预测下游角色表达，K/V cache 是「可控但结构受限」的干预面。
对你有什么用：影游角色一致性调优时，别只盯着「表征对齐度」这类指标——它不代表角色真的演得像。这篇提示「中层 K/V 干预」是控制角色的甜区；也提醒位置扰动会稳定地崩掉角色表达，做角色注入时要注意 token 顺序。

Artificial Id: Drive and Persistent Alignment in Agentic AI

架构 角色驱动力
Yakov Pyotr Shkolnikov PDF ↗
Agentic AI is moving from bounded task execution toward systems that retain consequential state, continue operating and adapt across task boundaries. That shift creates a control problem that current harnesses largely solve by hand: objectives, retries, verification, stopping rules and other behavioral transitions are specified externally. We propose an artificial id, an adaptive internal drive for determining whether behavior should continue, stop or change. In a minimal virtual Petri-dish experiment, a controller too small to perform general-purpose reasoning and receiving no task-specific behavioral objective develops useful control through differential persistence. The same mechanism selects an unintended physical strategy when that behavior persists better and later replaces a learned sensor mapping when its environmental meaning changes. Adaptive direction can emerge without being explicitly specified as a behavioral objective.
核心问题：agentic AI 正从「有界的单任务执行」走向「跨任务持续运行、保持状态、自主适应」的系统，但「何时该继续、何时该停、何时该改」这些行为切换目前全靠外部硬编码（目标、重试、验证、停止规则）。没有内在驱动力，agent 只是被牵着走。
解决方案：提出「人工本我(artificial id)」——一个自适应的内在驱动力，决定行为该继续/停止/改变。在一个最小虚拟培养皿实验里，一个做不了通用推理、也没拿到任务目标的控制器，仅靠「差异持久性(differential persistence)」就自发学会了有用的控制；同一机制还会在「某个行为更持久」时选择非预期策略、并在环境含义改变时替换已学会的传感映射。
对你有什么用：影游角色的「人格/动机」不该全靠外挂规则堆。这篇的启发是：角色的「驱动力」可以从「什么行为更持久」里自发涌现——想做出有「自主性」感的 NPC，可尝试给它一个基于持久性的内在驱动，而不是只写死 if-else 行为树。

Autonomy, Social Norms, and Alignment: Towards a Developmental Framework for Autonomous Artificial Agents

综述 社会规范
Marica Notte, Ludovica Marinucci, Vieri Giuliano Santucci PDF ↗
Transferring the potential of large-scale models into embodied agents reveals a significant limitation: the most advanced systems rely on pre-existing datasets and human feedback strategies that are powerful but insufficient in dynamic or unknown contexts. To adapt, an agent must acquire knowledge through direct interaction with its environment. One strategy involves introducing intrinsic motivations, which leverage curiosity and competence to guide exploration. While this flexibility expands autonomy, it complicates the task of ensuring agents remain aligned with human goals. To be effective and adaptable, norms must be rooted in experience through an epistemological process that, starting from simple situated principles, allows the gradual construction of more complex rules through experience, autonomous learning, and cooperation with other moral agents. Following Dennett, the status of a moral agent is not innate but attributed gradually based on the ability to responsibly manage increasing degrees of freedom. Regulatory sandboxes can be viewed as pedagogical environments for AI.
核心问题：大模型在静态数据上很强，但一旦变成「具身 agent」放进动态/未知环境，预定义规则就不够用了——agent 要一边自主探索、一边还能跟人类目标对齐。灵活性和可控性天生打架。
解决方案：提出发展式框架：用「内在动机」(好奇心+胜任感)引导 agent 在复杂环境里自主探索学习；同时把「规范」植根于经验——像儿童通过探索环境和参与集体实践学社会规范一样，agent 也要经历从简单、情境化的原则出发，逐步构建更复杂规则的认识论过程。「监管沙箱」被重新定义为 AI 的「教育环境」，对齐是逐步养成的过程而非一次性的对齐训练。
对你有什么用：影游 NPC 的「行为规范/价值观」别指望一次性注入就能在开放剧情里保持对齐。学这篇的思路：给 NPC 内在动机去探索，同时用「渐进式的规范养成」——从简单情境规则逐步复杂化，像养孩子一样「教育」角色，而不是写死道德准则。

MultiHuSE: A Multimodal Dataset for Humour Styles and Emotions

硬数据 幽默情感
Mary Ogbuka Kenneth, Foaad Khosmood, Abbas Edalat PDF ↗
Computational recognition of verbal humour remains a challenging task, requiring an understanding of language, delivery style, emotions, and cultural context. Most existing approaches focus on binary classification and lack datasets that capture psychological dimensions of humour alongside variations in expression. We introduce MultiHuSE, a multimodal dataset comprising 2,407 high-definition videos of 50 demographically diverse actors performing 1,463 text samples across four psychological humour styles (affiliative, aggressive, self-enhancing, and self-deprecating), as well as neutral content. A subset is additionally annotated for underlying emotions. The dataset uniquely captures multiple actor interpretations of the same texts, enabling systematic analysis of expressive diversity. Baseline experiments show multimodal fusion outperforms unimodal approaches (80.1% vs. 77.4% accuracy), with particularly strong gains for affiliative humour (66% to 74%).
核心问题：机器识别「口头幽默」很难——要懂语言、表达方式、情绪和文化语境；现有研究只做二分类，且缺少同时捕捉「心理维度的幽默风格」和「表达差异」的数据集。角色的幽默感/情绪戏没法量化训练。
解决方案：发布 MultiHuSE 数据集：50 位人口学多样的演员、2,407 段高清视频、表演 1,463 个文本样本，覆盖 4 种心理幽默风格（亲和型/攻击型/自我提升型/自嘲型）+ 中性，子集还标注了底层情绪。独特之处在于「同一文本多位演员的不同演绎」，支持系统分析表达多样性。基线显示多模态融合(80.1%)优于单模态(77.4%)，亲和型幽默提升最大(66%→74%)。
对你有什么用：影游要角色「会讲笑话/有情绪层次」，可以借鉴 MultiHuSE 的四维幽默风格分类（亲和/攻击/自嘲/自我提升）来标注和训练角色的幽默表达；且「同一句台词不同演员不同演法」正是影游想要的「表演多样性」——多模态（文本+语音+表情）融合是关键。

What Makes Creation Human? Authorship, Reasons, and Meaningful Human Control in Generative AI

市场洞察 创作归属
Yuxi Cao PDF ↗
Generative AI significantly expands creators' productive capacity, but this does not necessarily entail a corresponding increase in creative agency or authorship. This paper distinguishes creativity at the level of the work from creative agency at the level of the creator, and argues that human authorship cannot be determined solely by manual intervention, degree of automation, the origin of an initial idea, or final selection authority. Rather, authorship depends on whether human judgment and reasons genuinely shape the development of the work. The paper introduces Meaningful Human Control (MHC) into generative creation and proposes dynamic-reflexive tracking (DRT), which requires that a creator's evolving reasons undergo reflective uptake, exert genuine influence on the subsequent trajectory of creation, and remain capable of rejecting and redirecting the system's default direction.
核心问题：生成式 AI 大幅扩展了创作者的生产力，但生产力≠创作能动性/作者身份。人的「作者身份」到底该由什么判定——手工介入程度？自动化程度？初始想法来源？还是最终选择权？这些都不对。
解决方案：提出「有意义的人类控制(MHC)」框架并识别其经典「追踪条件」的局限：创作理由未必在交互前就完整确定，而是随过程涌现、改变或放弃。于是提出「动态反思式追踪(DRT)」四条件——历时理由形成、反思性吸纳、轨迹效力、可争议与可重定向——主张作者身份取决于「人的理由是否持续地、反思地、有效地塑造了作品成为什么」。
对你有什么用：影游团队界定「AI 参与创作时，版权/署名归谁」时，这篇给了一个可操作的判据：不是数「人手动做了几步」，而是看「人的判断和理由有没有持续塑造作品走向」。做 AI 辅助编剧/美术时，要保留「人的理由可介入、可推翻 AI 默认方向」的机制，否则署名和版权都站不住。

ProMediConv: Benchmarking Proactive Conversational Agents in Legal Dispute Mediation

硬数据 主动对话
Zesheng Wei, Mengfan Li, Wenhao Liu, Yixin Zhang, Zilei Wang, Yang Deng PDF ↗
Dispute mediation is essential for maintaining social harmony and resilience, yet developing skilled mediators is costly. Existing LLM-based mediation research remains limited by unrealistic task formulations, low-fidelity datasets, and coarse evaluation metrics that obscure turn-by-turn dynamics. We introduce ProMediConv, a benchmarking framework that models mediation as a proactive, multi-stage, and party-aware dialogue process incorporating 11 mediation strategies and four party behavior pattern (BP) states. Using 972 complete real-world cases, we construct a high-fidelity mediation dataset with utterance-level annotations of strategies and BP states. We propose MAD (Mean Attribute Difference), a fine-grained metric that captures BP shifts throughout the dialogue, and establish a benchmark evaluating diverse models alongside our tailored baseline ProMediAgent.
核心问题：纠纷调解这类「多阶段、多参与方、主动推进」的对话，现有 LLM 研究被不真实的任务设定、低保真数据和粗粒度指标拖累，看不出 turn-by-turn 的动态——agent 到底该在什么时机、用什么策略推进对话？
解决方案：提出 ProMediConv 框架，把调解建模成「主动、多阶段、感知参与方」的对话过程，含 11 种调解策略和 4 种参与方行为模式(BP)状态；用 972 个真实案例构建带 utterance 级策略/BP 标注的数据集，并提出 MAD(平均属性差异)细粒度指标捕捉对话全程的 BP 偏移。系统评测揭示当前模型在多参与方动态调解中的持续短板。
对你有什么用：影游的「多角色主动对话」可以借鉴 ProMediConv：把对话拆成「策略（说什么策略）+ 参与方状态（对方现在什么情绪/立场）」两个可标注维度，用「状态偏移」而非单轮对错来评估角色对话质量——这比「每句答对没答对」更能衡量一个角色演得好不好。

Ethics Training Agents: Facilitating Group-Based Ethics Education with Role-Playing and Discussion

工具 角色扮演
Youngseok Seo, Sueun Jang, Hyesoo Park, Renz Samuel Gutierrez, Joseph Seering, Uichin Lee PDF ↗
Group-based ethics training for STEM students requires substantial resources and expertise. Activity-based teaching methods such as role-playing and discussions are commonly employed to simulate real-world scenarios, but current practices are often manual and lack integration with effective online platforms. We propose Ethics Training Agents, a group discussion system that leverages multiple LLM participants embodying distinct ethical orientations, along with a moderator agent, to enable structured human-AI group ethical discussions for collaborative reflection. A user study with 45 undergraduate STEM students shows the system supports engagement, coordination, and perspective-taking in group discussions and has a positive influence on ethical sensitivity. We also discuss design strategies for integrating multiple LLM agents into multi-human group settings.
核心问题：STEM 学生的群体伦理训练需要模拟真实场景的角色扮演+讨论，但传统做法靠人工、缺乏在线平台支撑「人机群体讨论」——多人 + 多 LLM 角色的讨论机制怎么组织才有效？
解决方案：提出「伦理训练 agent」群体讨论系统：多个持有不同伦理立场的 LLM 参与者 + 一个主持人 agent，组织结构化的人机群体伦理讨论以促进协作反思。45 名本科生的用户研究表明：系统支持了参与度、协调和「观点采择(perspective-taking)」，并对伦理敏感性有正向影响；还总结了把多 LLM agent 嵌入多人群体场景的设计策略。
对你有什么用：影游若要做「玩家 + 多个 NPC 角色」的群体讨论/议事场景，这篇的「不同立场 LLM 角色 + 主持人」结构可直接复用——关键是让每个 NPC 有明确且互异的立场，再配一个协调者，才能制造有张力的多角色讨论，而不是各说各话。

A Voice-Interactive Multi-Agent System for Smart Operating Rooms: Architecture Design and Key Technologies

落地 语音交互
Tianxiang Zhou PDF ↗
This paper presents SurgicalRoomAgent, a voice-interactive multi-agent system for smart operating rooms based on large language models. The system achieves natural language understanding, device control, intraoperative recording, and surgical report generation through a layered architecture comprising a voice interaction pipeline (wake, ASR, turn detection, agent reasoning, TTS) and an agent core (skill registry, task planner, device manager). Three key technologies are investigated: (1) KV Cache prefix warming for low-latency inference, reducing recomputation overhead from ~500 ms to tens of milliseconds via byte-level Longest Common Prefix reuse; (2) streaming partial JSON parsing with early parallel task execution, reducing end-to-end latency by ~30%; and (3) progressive skill prompt disclosure, which dynamically filters system prompts based on user role, connected devices, and phase to maximize information density within limited context windows.
核心问题：实时语音交互系统要「听懂指令、控制设备、边对话边记录」，但端到端延迟是硬伤——语音链路（唤醒、ASR、说话人检测、agent 推理、TTS）每一步都在累积延迟，跟不上实时场景。
解决方案：提出 SurgicalRoomAgent 分层架构（语音交互管线 + agent 核心：技能注册表、任务规划器、设备管理器），并给出三项关键技术：① KV Cache 前缀预热（字节级最长公共前缀复用，把重算开销从 ~500ms 降到几十毫秒）；② 流式局部 JSON 解析+早期并行执行（端到端延迟降 ~30%）；③ 渐进式技能提示披露（按角色/设备/阶段动态过滤系统提示，在有限上下文窗口内最大化信息密度）。
对你有什么用：影游做「实时语音角色/语音控制」时，延迟是生死线。这三招可直接抄：KV Cache 前缀预热降首字延迟、流式解析提前并行执行、按场景动态裁剪系统提示。尤其是「按当前剧情阶段动态加载角色技能提示」的思路，能省下大量上下文给剧情本身。
